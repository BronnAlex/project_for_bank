## Использование:
Использовать необходимо для обработки входных данных карты, счёта или даты.
src/masks.py - Возвращает вам маску карты или счета. 
src/widget.py - Обновленная версия маски и счета, без выбора функции маски 
src/processing.py - Фильтрация списка словарей и сортировка даты по ключам
src/generators.py - Добавил функцию фильтрации по заданной валюте. Функцию, которая возвращает описание того, что делали
переводили кому-то на карту или счет или возможно оплатитили на счет компании 
src/decorators.py - Создал модуль с декоратором по обработки входных данных с использованием файла, если он есть.
Также создал новую функцию, генератор номера банковской карты.
src/utils - Создал модуль с обработкой json файла с транзакциями по банковским операциям.
src/external_api.py - В модуле реализован запрос GET по url  и api key
src/reading_csv_xlsx_files.py - В модуле реализованы функции по чтению файлов csv и xlsx
